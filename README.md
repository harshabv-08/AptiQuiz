AptiQuiz – Java Quiz System

AptiQuiz is a Java-based quiz and examination application designed to help students practise aptitude, programming, and technical interview questions.

Features
- User-friendly graphical interface built with Java Swing
- Quiz categories for aptitude and technical subjects
- Multiple-choice questions
- MySQL database connectivity using JDBC
- Organized Java source code using separate UI, model, DAO, and utility packages

Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- Visual Studio Code

Project Structure
- "src/" – Java source code
- "lib/" – Required Java libraries
- ".vscode/" – Visual Studio Code project configuration

Getting Started

Prerequisites
- Java Development Kit (JDK)
- MySQL Server
- Visual Studio Code with Java support
- MySQL Connector/J JDBC driver

Setup
1. Clone or download this repository.
2. Create the required MySQL database and tables using the project's database setup instructions.
3. Configure the database connection in the appropriate Java configuration file.
4. Ensure the MySQL JDBC driver is available on the project's classpath.
5. Open the project in Visual Studio Code and run the main Java class.

Purpose
This project was developed as a college Java project to practise object-oriented programming, GUI development, database connectivity, and application design.
